## Deviations from the Bible and assumptions

- Document files are stored in PostgreSQL with a 10 MiB cap, not in object storage (ADR 0018, with the migration path).
- The Bible's document states are stored as the repository's existing statuses (DRAFT, SUBMITTED, APPROVED, SUPERSEDED).
- The web console is framework-free JavaScript, not React/TypeScript; kept because it works and is tested.
- Tenant identity comes from the database login, which is stronger than the Bible's session-variable example; kept.
- An RFI may be answered by any holder of `document.manage` on the project other than its author, not only the named assignee. Change this if answers must come from the assignee.
- Role grants for the new permissions (upload: site engineer, quantity surveyor, planner; publish: project manager) are a proposal for the product owner.
